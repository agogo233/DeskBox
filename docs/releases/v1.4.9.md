# DeskBox 1.4.9

DeskBox 1.4.9 is a memory-lifecycle release focused on fixing unbounded memory growth, restoring idle memory compression, and hardening file interactions.

Released on September 1, 2026.

## Highlights

- **Settings window no longer leaks.** Each open/close cycle of the Settings window used to leak a full native XAML tree (~10 MB) through a known WinUI 3 window-close defect. The window is now reused: closing hides it, and reopening refreshes the same instance.
- **Deep cleanup actually runs.** The idle deep finalizer collection retries with backoff when its cooldown vetoes a run, instead of silently marking the stage complete.
- **Material switching stops accumulating handles.** System backdrop controllers are reused across material changes (their kind is mutable), and DWM theme attributes are only re-issued when the theme flips.
- **Idle memory compression is back.** A new "Compress memory when idle" setting (on by default, Performance section) restores the pre-1.4.5 behaviour: after the hidden-idle deep cleanup, the working set is paged out (measured 350 MB down to under 10 MB). While widgets are visible it only runs when the user is fully away and both footprints exceed the original bloat thresholds, so ambient animations and frame pacing stay smooth.
- **Safer file interactions.** File opening is gated, traced, and runs on a bounded STA runner with opening animations and text scaling; renaming to another extension asks for confirmation; the stack popover supports in-place rename.
- **Startup registration refactor.** Direct and store startup services are split out with contract tests.
